# ขอบเขตเริ่มต้น

ผู้ใช้ระบบเป็นเจ้าหน้าที่ ลูกค้าเป็นข้อมูลผู้ซื้อและผู้รับสินค้า ไม่มี customer portal
ใช้ .NET 10, Angular 21, SQL Server และ DBeaver
ชื่อโครงสร้างอ้างอิง ERP Backoffice; ชื่อโฟลเดอร์ repository บนเครื่องคงเป็น ERP-Stock

## มีโค้ดในรอบนี้

- solution/project references ครบ 4 ชั้น
- Entity 12 ตัวตามรายการผู้ใช้ พร้อม EF configurations และ DbContext
- Repository เบื้องต้นสำหรับอ่าน/เพิ่มข้อมูล และ UnitOfWork
- health endpoint ของ API
- Angular layout, เมนู และ placeholder routes ตามโครง
- initial EF migration, SQL export และ ERD โดยไม่ได้เชื่อมต่อ SQL Server จริง

## งานที่ยังไม่เปิดใช้งาน

- login, roles, guards และการตรวจสิทธิ์ฝั่ง API
- CRUD สินค้า/ลูกค้า/คลัง และการรับเข้าสินค้า
- การตรวจสินค้า จอง ยืนยัน order และป้องกัน overselling
- QR payload จริง การตรวจเงินเข้า และการเลือกธนาคาร/payment provider
- ใบเสร็จ/ใบส่งของและการสร้าง PDF จาก snapshot
- handlers ของการเตรียม ส่งสินค้า ตัดสต็อก ยกเลิก และ idempotency
- seed ที่รันได้ และการใช้ migration กับ SQL Server

## สมมติฐานสำหรับแบบเริ่มต้น

หนึ่งบริษัท เงินบาท ชำระเต็มและส่งครบหนึ่งครั้งต่อ order โดยเลือกคลังของแต่ละ order
จองสินค้าเมื่อยืนยัน order แต่ตัด OnHand หลังส่งตาม flow ที่กำหนด
ใช้ Finance ตรวจเงินจริงก่อนยืนยันการชำระ; QR หรือสลิปอย่างเดียวไม่ถือว่าจ่ายสำเร็จ
ใบเสร็จรับเงินในขอบเขตนี้ยังไม่ใช่โมดูลใบกำกับภาษี

ก่อนเปิดธุรกรรมจริงต้องกำหนดเพิ่มเติมเรื่องหน่วยนับ/แปลงหน่วย, ส่วนลด/ภาษี/ค่าขนส่ง, ผู้มีสิทธิ์ยืนยันเงิน, เลขเอกสาร และการยกเลิก/คืนเงิน/คืนสินค้า
รุ่นเริ่มต้นยังไม่รองรับการจ่ายบางส่วนหรือส่งบางส่วน
